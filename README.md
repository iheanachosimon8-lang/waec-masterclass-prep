# WAEC Masterclass Prep

A mobile-friendly West African exam preparation and CBT practice starter.

## Current features
- Country selector for Nigeria, Ghana, Sierra Leone, The Gambia and Liberia.
- Starter practice in Mathematics, English Language, Biology, Chemistry, Physics and Economics.
- Multiple-choice questions with instant marking and explanations.
- Practice timer and local best-score/attempt tracking.
- Responsive layout for phones, tablets and desktops.
- No account required for the starter practice.

## Run locally
Open `index.html` in a browser, or serve this folder with any static web server.

## Deploy
Import this repository into Vercel. The project is a static site; no build command is required and the output directory is the repository root.

## Important notes
This is an independent learning resource and is not affiliated with or endorsed by WAEC. Starter questions are original practice examples, not official WAEC past questions. Subject availability, syllabuses and examination arrangements can differ by country and year. Check the relevant official WAEC country office for current requirements and announcements.
